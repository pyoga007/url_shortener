# Minimal Spring Boot Web Project

- Java / JDK: 21
- Build tool: Maven
- Dependency: Spring Web only
- Spring Boot: 3.5.6

## Run

Make sure JDK 21 is installed, then run:

```bash
./mvnw spring-boot:run
```

If the Maven Wrapper is not included, run with installed Maven:

```bash
mvn spring-boot:run
```

Open http://localhost:8080/ to see `Hello, Spring Boot!`.

Import into IntelliJ IDEA or Eclipse as an existing Maven project.
